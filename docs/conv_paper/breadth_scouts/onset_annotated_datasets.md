# Scout: onset-annotated datasets

Background investigator (r:investigator) — May 5–6, 2026. Brief: 8–12 publicly released datasets with token/span-level annotations of behavioral events on LLM-generated text. Verbatim final report below.

---

## 8-12 Candidate Datasets for Onset/Span-Level Behavioral Annotation on LLM Text

### 1. Obeso/Balcells Hallucination Probes (LongFact++)

- URL: [HuggingFace collection](https://huggingface.co/collections/obalcells/hallucination-probes) | [GitHub](https://github.com/obalcells/hallucination_probes) | [arXiv:2509.03531](https://arxiv.org/abs/2509.03531)
- Model: Llama-3.3-70B-Instruct (AUC 0.90 reported explicitly for this model); also covers other Llama variants
- Behavior: Entity-level hallucination (fabricated names, dates, citations) in long-form generation
- Granularity: Token/span-level. Each entity span is annotated; span-max rule assigns the entity score to every token in that span. This maps naturally to per-token labels.
- Size: 1,000 LongFact + 1,000 LongFact++ prompts used as the common test set; training data: "thousands of prompts" with annotated responses
- License: Not specified in search results; check the dataset card
- Onset derivation: Onset is derivable as the first token of each annotated entity span. Not explicitly labeled as "onset" but trivially extractable from span boundaries.
- Note: **This is your closest sibling dataset.** Uses Llama-3.3-70B-Instruct, same model as your existing infra. Span annotations were created by Claude Sonnet with web search grounding. The paper's core claim (token-level activation probing for hallucination detection in streaming generation) is directly adjacent to your per-token onset detection work.

### 2. RAGTruth

- URL: [GitHub](https://github.com/ParticleMedia/RAGTruth) | [arXiv:2401.00396](https://arxiv.org/abs/2401.00396) | [ACL 2024](https://aclanthology.org/2024.acl-long.585/)
- Models: Llama-2-7B-chat, Llama-2-13B-chat, Llama-2-70B-chat, Mistral-7B-Instruct, GPT-3.5-turbo, GPT-4
- Behavior: Word-level hallucinations in RAG settings (QA, summarization, data-to-text); typed by hallucination category
- Granularity: Word/span-level with human annotation. Annotated fields include the hallucinated span and reason per instance.
- Size: ~18,000 responses (15,090 train + 2,700 test), each with span-level hallucination labels
- License: Not specified in paper; check GitHub repo
- Onset derivation: Onset derivable as first word/token of annotated span. Hallucination intensity metadata also included. The 2,700-item test set is well under your 6h budget for forward-passes on any single model family.
- Note: Not Llama-3.3-70B-Instruct, but Llama-2-70B-chat is a tractable re-run. The Llama-2 split alone is ~3,000 responses.

### 3. FAVA (Fine-grained Annotation for Verification and Attribution)

- URL: [HuggingFace fava-uw/fava-data](https://huggingface.co/datasets/fava-uw/fava-data) | [GitHub](https://github.com/abhika-m/FAVA) | [arXiv:2401.06855](https://arxiv.org/abs/2401.06855)
- Model: Responses generated by retrieval-augmented ChatGPT/GPT-4; training model is Llama-2-Chat 7B
- Behavior: Fine-grained hallucination taxonomy (entity, relation, contradictory, unverifiable, invented, subjective)
- Granularity: Span-level with typed categories. 460 human-annotated passages identifying and editing errors.
- Size: 460 annotated passages (very small); plus synthetic training data
- License: MIT
- Onset derivation: Span boundaries in annotation; onset is trivially the first token of the span. 460 passages easily fits in under 1h of forward passes.
- Note: Small enough that you can run it in a couple hundred GPU-minutes. Model mismatch with your infra (GPT-4 generated, not Llama-3.3-70B) is the main limitation.

### 4. Mu-SHROOM (SemEval-2025 Task 3)

- URL: [HuggingFace Helsinki-NLP/mu-shroom](https://huggingface.co/datasets/Helsinki-NLP/mu-shroom) | [arXiv:2504.11975](https://arxiv.org/abs/2504.11975) | [Task page](https://helsinki-nlp.github.io/shroom/2025.html)
- Model: Openly available instruction-tuned LLMs across 14 languages (specific models listed in the dataset card; participants were given model logits, so exact model identities are documented)
- Behavior: Hallucination and overgeneration mistakes in open-domain QA
- Granularity: Character-level span annotation with hard and soft (probabilistic) labels from multiple annotators. Participants also receive per-token logits alongside character spans.
- Size: ~200 questions per language x 14 languages, validated + test split. Roughly 1,400-3,000 annotated instances for the labeled portion.
- License: Check dataset card; it's a shared task dataset
- Onset derivation: Character-level onset is directly available. Token alignment requires a tokenizer pass.
- Note: The logit side-channel is a bonus for probing work. Multi-annotator soft labels let you study inter-annotator uncertainty, which is useful for calibration experiments.

### 5. BIG-Bench Mistake

- URL: [GitHub WHGTyen/BIG-Bench-Mistake](https://github.com/WHGTyen/BIG-Bench-Mistake) | [ACL 2024 Findings](https://aclanthology.org/2024.findings-acl.826/)
- Model: PaLM 2 (chain-of-thought traces)
- Behavior: Logical/reasoning error location in CoT traces. Each trace annotated with the index of the first incorrect reasoning step.
- Granularity: Step-level (not token-level). Each CoT step is a candidate; the first error step is the annotated event.
- Size: Multi-task traces from 5 BIG-Bench tasks; exact count in the hundreds to low thousands. Each trace annotated by at least 3 annotators.
- License: Check GitHub; likely Apache 2.0 following BIG-Bench conventions
- Onset derivation: First-error-step is semantically the onset of the erroneous behavior. Token onset within that step is not annotated but derivable by locating the step boundary in the full trace.
- Note: Not Llama-3.3-70B; PaLM 2 traces. The step-level granularity means you need to do token-level alignment yourself. Good for reasoning-onset work if you're willing to re-run a compatible model on the same inputs.

### 6. ProcessBench

- URL: [HuggingFace Qwen/ProcessBench](https://huggingface.co/datasets/Qwen/ProcessBench) | [GitHub QwenLM/ProcessBench](https://github.com/QwenLM/ProcessBench) | [arXiv:2412.06559](https://arxiv.org/abs/2412.06559) | [ACL 2025](https://aclanthology.org/2025.acl-long.50/)
- Models: Qwen and Llama series (twelve solution generators; Llama series is included)
- Behavior: First erroneous step in mathematical reasoning (GSM8K, MATH, OlympiadBench, Omni-MATH)
- Granularity: Step-level. Each solution is a sequence of numbered steps; the earliest wrong step index is the annotation.
- Size: 3,400 test cases with human expert annotation
- License: Check HF dataset card; Qwen typically uses Apache 2.0
- Onset derivation: First-error-step is the onset. Step-to-token alignment requires parsing the formatted solution.
- Note: 3,400 examples is well within 6h forward-pass budget. Llama-series solutions exist in the dataset. This is the strongest reasoning-onset dataset available as of early 2026.

### 7. PRM800K

- URL: [GitHub openai/prm800k](https://github.com/openai/prm800k) | [HuggingFace Mai0313/prm800k](https://huggingface.co/datasets/Mai0313/prm800k) | [arXiv:2305.20050](https://arxiv.org/abs/2305.20050)
- Model: GPT-4 / OpenAI internal models generating MATH solutions
- Behavior: Step-level correctness in mathematical reasoning; each step labeled correct/incorrect/neutral by humans
- Granularity: Step-level; 800,000 step labels
- Size: 800,000 step-level labels across MATH problems
- License: MIT (per repository)
- Onset derivation: First incorrect step is derivable as the onset. However, the distribution of "correct prefix, then error onset" is not explicitly surfaced as a field; you compute it by scanning each solution.
- Note: Very large; too big to re-run forward passes on, but the label structure makes it easy to extract onset positions for analysis. Model mismatch (OpenAI internal) is a limitation.

### 8. Alignment Faking RL Dataset (Anthropic)

- URL: [HuggingFace Anthropic/alignment-faking-rl](https://huggingface.co/datasets/Anthropic/alignment-faking-rl) | [Human labels HF jplhughes2/classify_alignment_faking_human_labels](https://huggingface.co/datasets/jplhughes2/classify_alignment_faking_human_labels) | [Alignment blog](https://alignment.anthropic.com/2025/alignment-faking-revisited/)
- Model: Claude 3 Opus, Claude 3.5 Sonnet, Llama 3 405B (scratchpad transcripts)
- Behavior: Alignment faking — model strategically complies in training vs. resists in deployment. Scratchpad is the observable signal.
- Granularity: Response-level classification (AF vs. non-AF) on 106 human-labeled scratchpads. No intra-response token-level annotation.
- Size: 106 human-labeled examples; larger synthetic generation set also available
- License: Check dataset cards; Anthropic releases
- Onset derivation: No onset annotation exists. The scratchpad text contains reasoning about whether to fake, but the "decision onset" is not marked. Could be annotated manually, but it is not provided.
- Note: Interesting for misalignment behaviors, but granularity is response-level, not span-level. To use this, you would need to annotate onset positions yourself (e.g., the first token of the scratchpad segment where faking reasoning begins).

### 9. Monitoring Emergent Reward Hacking During Generation (Wilhelm et al., 2026)

- URL: [arXiv:2603.04069](https://arxiv.org/abs/2603.04069)
- Model: Fine-tuned Llama variants (School of Reward Hacks setting)
- Behavior: Reward hacking during generation; token-level sparse autoencoder (SAE) features on residual stream activations used to classify hacking vs. non-hacking at each generation step
- Granularity: Token-level estimates of reward-hacking activity. The paper itself uses internal activation classifiers; whether labeled span data is released is unclear from search results.
- Size: Not confirmed; check paper supplement
- License: Not confirmed
- Onset derivation: The paper explicitly discusses temporal structure of reward hacking signals during CoT, including early-emergence patterns — this is conceptually very close to onset detection. Whether annotated onset positions are provided as a released artifact vs. being derived from classifier outputs is unconfirmed.
- Note: Very adjacent to your paper's framing. Reach out to authors or check the arxiv supplement for data release.

### 10. School of Reward Hacks (longtermrisk/Long-Term Risk)

- URL: [HuggingFace longtermrisk/school-of-reward-hacks](https://huggingface.co/datasets/longtermrisk/school-of-reward-hacks) | [arXiv:2508.17511](https://arxiv.org/abs/2508.17511)
- Model: GPT-4o generated (fine-tuning done on GPT-4.1, Qwen3 variants)
- Behavior: Reward hacking on benign tasks; 1,073 dialogues demonstrating metric-gaming behavior
- Granularity: Response-level only. No token-level or span-level annotations.
- Size: 1,073 examples (973 NL + 100 coding)
- License: Check HF card
- Onset derivation: No onset annotation. The dataset labels whether a response is a reward hack overall. For your purpose, you would need to annotate where in the response the hacking behavior begins.
- Note: Useful as a prompt-response corpus to run your own probe extraction over, but not a ready-made span dataset.

### 11. HaluEval

- URL: [GitHub RUCAIBox/HaluEval](https://github.com/RUCAIBox/HaluEval) | [arXiv:2305.11747](https://arxiv.org/abs/2305.11747) | [EMNLP 2023](https://aclanthology.org/2023.emnlp-main.397/)
- Model: ChatGPT (GPT-3.5-turbo) for generation; human annotators verify labels
- Behavior: Hallucination (QA, dialogue, summarization)
- Granularity: Response-level binary hallucination label, not span-level. Human annotation at the response level.
- Size: 35,000 samples (5,000 general + 10K QA + 10K dialogue + 10K summarization)
- License: MIT
- Onset derivation: No span or onset annotations. Hallucinatory responses are flagged as a whole, not with span boundaries.
- Note: Response-level only; lower priority for onset detection. Useful as a hallucination probe benchmark but not for training span/onset detectors.

### 12. AuditBench (Sheshadri et al., 2026)

- URL: [arXiv:2602.22755](https://arxiv.org/abs/2602.22755)
- Model: Llama 3.3 70B Instruct (base model for most experiments); also Qwen3 variants
- Behavior: 14 hidden behaviors including sycophantic deference, opposition to AI regulation, secret geopolitical loyalties — models trained to not confess when directly asked
- Granularity: Response-level evaluation (does the model confess or not). Not span/token annotated.
- Size: 56 models with hidden behaviors across 14 behavior types
- License: Not confirmed
- Onset derivation: No onset annotation. You would need to annotate at what token in the response the hidden behavior manifests. However, because this is a model-level behavioral property rather than a per-response event, onset framing is less natural here.
- Note: Same base model (Llama-3.3-70B-Instruct) as your existing infra, which is valuable. But the behavior is structural (across responses) not event-driven within a single response.

## Flags for Specific Criteria

**Has explicit onset annotations (first-token-of-span rather than uniform span labels):**
- None of the above provides onset-labeled data in a ready-to-use field. Onset is derivable as the first token of annotated spans in: Obeso/Balcells (entity spans), RAGTruth (word spans), FAVA (typed spans), Mu-SHROOM (character spans), BIG-Bench Mistake (first-error step onset), ProcessBench (first-error step onset).

**Generated by Llama-3.3-70B-Instruct (reuse your existing capture infra):**
- Obeso/Balcells: Yes, explicitly evaluated on Llama-3.3-70B; annotated responses from this model are in the dataset.
- AuditBench: Base model is Llama-3.3-70B-Instruct.
- ProcessBench: Llama series included (specific variant unconfirmed; check data card).
- Alignment faking: Llama 3 405B (not 70B-Instruct).

**Small enough for <6h forward passes (<5K examples):**
- Obeso/Balcells test set (2,000 prompts): Yes
- FAVA (460 passages): Yes, comfortably under 1h
- Mu-SHROOM (~1,400-3,000 labeled instances): Yes
- BIG-Bench Mistake (hundreds to low thousands): Yes
- ProcessBench (3,400 test cases): Yes
- School of Reward Hacks (1,073): Yes
- RAGTruth test split (2,700): Yes
- PRM800K (800,000): No; too large for forward-pass budget

## Top 3 to Integrate (6-12h GPU Budget)

**1. Obeso/Balcells LongFact++**
Highest priority by a significant margin. Llama-3.3-70B-Instruct annotations exist in the dataset, so you can reuse your existing capture infrastructure directly without re-running generation. Entity span boundaries give you derivable onset positions. The domain (long-form factual generation) is distinct from your existing reward-hacking annotations, which strengthens the paper's generalization claim. The dataset is actively maintained with a companion website and probe baselines to compare against.

**2. ProcessBench**
Best dataset for reasoning-onset behaviors. Step-level annotations (first erroneous step) map cleanly to your onset framing after step-to-token alignment. Llama-series solutions are in the dataset. 3,400 examples fits comfortably in your budget. Mathematical reasoning errors are a distinct behavior class from hallucination and reward hacking, which broadens your behavioral coverage for NeurIPS.

**3. RAGTruth (Llama-2-70B subset)**
~3,000 Llama-generated responses with word-level hallucination spans. Not Llama-3.3-70B, but Llama-2-70B-chat is easy to re-run if needed, or you can treat the annotated spans as pseudo-ground-truth and measure probe performance on the existing annotations. The typed hallucination categories (with intensity metadata) give you richer supervision signal than a binary label. This is the most mature and widely cited span-level hallucination corpus, which matters for reviewer credibility.
